About @media Queries

@media queries are most commonly used for responsive screen sizes. You will learn about other use cases for @media and how it also helps with accessibility and more!

prefers-contrast: Some users will manually set the browsers to have higher or lower contrast because of their vision. This allows us to choose what colors they see on our site with a contrast difference using : more; : less; no-preference (default)

:hover Devices like phones don't have the ability to hover. That's why we use a media query that checks if the device can over and reacts differently.

pointer: Similar to :hover, we can't use pointer on phones, so we need to input an @media query that gives a fallback for devices without the capability. (44px minimum for button, a, input, select)

Safe-Area Evironment variables env(safe-area-inset-[top, bottom, left, right]) This is used for devices that have parts of the device covered like phones that have the camera on the front screen making it no longer a rectangle of screen.
